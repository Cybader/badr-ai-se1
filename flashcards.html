Hardware

العتاد — المكونات المادية للحاسوب (CPU، RAM، قرص، لوحة أم…)

Indice : Matériel

Software

البرمجيات — البرامج والتطبيقات التي ينفذها العتاد

Indice : Programmes

CPU (processeur)

المعالج — ينفذ التعليمات؛ يتكون من UCC وUAL وسجلات وساعة

Indice : Unité centrale

RAM

الذاكرة الحية — ذاكرة متطايرة تعمل كمساحة عمل للبرامج

Indice : Random Access Memory

ROM

الذاكرة الميتة — للقراءة فقط، تحتوي BIOS

Indice : Read Only Memory

Bus

الناقل — أسلاك تنقل البيانات بين مكونات اللوحة الأم

Indice : Transport de données

Chipset

شريحة التحكم — توجه تبادلات البيانات على النواقل

Indice : Jeu de composants

UAL

الوحدة الحسابية والمنطقية — تنفذ العمليات الحسابية والمنطقية

Indice : Unité arithmétique et logique

UCC

وحدة التحكم — تجلب التعليمات وتفككها وتشرف على تنفيذها

Indice : Unité de commande et de contrôle

Noyau (kernel)

النواة — الجزء الأساسي الذي يدير العمليات والذاكرة والملفات والأجهزة

Indice : Cœur du SE

Shell

مفسر الأوامر — واجهة المستخدم مع النظام (bash، sh…)

Indice : Interpréteur

Boot loader (GRUB)

محمل الإقلاع — يختار ويحمّل نظام التشغيل بعد BIOS

Indice : Démarrage

BIOS

نظام الإدخال/الإخراج الأساسي — يهيئ العتاد عند التشغيل

Indice : Dans la ROM

Ordonnanceur

المجدول — يقرر من يعمل من العمليات ومتى

Indice : Gestion des tâches

Swapping

التبديل — نقل صفحات من الذاكرة إلى القرص والعكس

Indice : Mémoire saturée

Inode

عقدة الفهرس — بنية تخزن ميتاداتا الملف ورقمه الفريد

Indice : Métadonnées

رابط صلب — اسم إضافي لنفس الـ inode (نفس البيانات)

رابط رمزي — ملف يحوي مسار الهدف؛ يُنشأ بـ ln -s

Répertoire

Indice : Dossier

Chemin absolu

مسار مطلق — يبدأ من الجذر / مثل /home/etudiant

مسار نسبي — ينطلق من المجلد الحالي مثل ../docs

Indice : Depuis le cwd

Pipe ( | )

أنبوب — يمرر خرج أمر كدخل لأمر آخر

Redirection

إعادة توجيه — تحويل قنوات الإدخال/الإخراج إلى ملفات

Indice : > >> < 2>

stdin / stdout / stderr

القنوات القياسية: 0 إدخال، 1 إخراج، 2 أخطاء

Indice : Descripteurs

Permission

إذن وصول — r قراءة، w كتابة، x تنفيذ

Indice : Droits

umask

قناع الأذونات — يحدد الأذونات الافتراضية للملفات الجديدة

Root

المستخدم الخارق — كل الصلاحيات، دليله #

مجموعة — تجميع مستخدمين لتقاسم الأذونات

أرشيف — تجميع ملفات في ملف واحد، مع ضغط اختياري

Processus

عملية — برنامج قيد التنفيذ له PID وحالة

Indice : ps

PID / PPID

معرف العملية / معرف العملية الأب

Indice : Identifiants

Signal

إشارة — رسالة بين العمليات مثل SIGKILL (9)

Indice : kill

Script

سكربت — ملف أوامر قابل للتنفيذ يبدأ بـ #!/bin/bash

Indice : Programme shell

Shebang

السطر #! الذي يحدد مفسر السكربت

Variable d'environnement

متغير بيئة — موروث من الأب إلى الأبناء (PATH، HOME…)

معامل موضعي — وسيط السكربت: $1، $2… و$0 اسم السكربت

تعبير نمطي — نمط لوصف ومطابقة السلاسل

محرف بديل في القشرة — * ? [a-z] لأسماء الملفات

توزيعة — نواة + أدوات + تطبيقات + مدير حزم

Commandes Unix

28 cartes · الأوامر

ls -l

عرض تفصيلي: الأذونات، المالك، المجموعة، الحجم، التاريخ والاسم

Indice : Liste longue

cd / cd .. / cd ~

التنقل: إلى الجذر / الأب / المجلد الشخصي

Indice : Change directory

pwd

طباعة مسار المجلد الحالي

Indice : Print working directory

mkdir -p a/b/c

إنشاء مجلد مع كل الآباء الناقصين

Indice : Make directory

cp -r src dest

نسخ مجلد مع محتواه بشكل متكرر

Indice : Copy

mv a b

نقل أو إعادة تسمية

Indice : Move

rm -r dossier

حذف مجلد وكل محتواه (احذر: لا رجوع)

Indice : Remove

touch fichier

إنشاء ملف فارغ أو تحديث تاريخه

Indice : Créer

cat fichier

عرض محتوى ملف أو دمج ملفات

Indice : Concaténer

head -n 5 / tail -n 5

أول / آخر خمسة أسطر من ملف

Indice : Début / fin

wc -l fichier

عدّ الأسطر (-w كلمات، -c محارف)

Indice : Word count

grep -i motif fichier

بحث عن نمط داخل المحتوى مع تجاهل حالة الأحرف

Indice : -v عكس، -n أرقام

find /home -name "*.c"

بحث في الشجرة حسب الاسم أو الخصائص

Indice : Recherche

cut -d: -f1 /etc/passwd

استخراج الحقل الأول بفاصل النقطتين

Indice : Colonnes

sort -n fichier

ترتيب رقمي (-r عكسي)

Indice : Trier

chmod 755 fichier

rwxr-xr-x — تنفيذ للجميع، كتابة للمالك فقط

Indice : Octal

chmod 644 fichier

rw-r--r-- — قراءة للجميع، كتابة للمالك

Indice : Fichier standard

chmod u+x script

إضافة حق التنفيذ للمالك (رمزي)

Indice : Symbolique

chown user:group fichier

تغيير المالك والمجموعة (root غالبًا)

Indice : Propriétaire

ln -s cible lien

إنشاء رابط رمزي

Indice : Symbolique

tar -czf a.tar.gz dossier

إنشاء أرشيف مضغوط بـ gzip

Indice : -xzf للاستخراج

ps -f

عرض تفاصيل العمليات (PID، PPID، CMD…)

Indice : Process status

kill -9 PID

إيقاف إجباري لعملية (SIGKILL)

Indice : -15 لطيف

cmd1 && cmd2 / cmd1 || cmd2

تنفيذ شرطي: الثانية إذا نجحت الأولى / إذا فشلت

Indice : Séparateurs

ls -l | wc -l

تمرير خرج الأمر الأول إلى الثاني وعدّ الأسطر

Indice : Pipe

command > f / >> f / 2> f

استبدال ملف / إلحاق / توجيه الأخطاء

Indice : Redirections

history

عرض سجل الأوامر (التنقل بـ ↑/↓)

Indice : Historique

man commande

عرض دليل الاستخدام الكامل للأمر (q للخروج)

Indice : Manuel

Concepts & notations

19 cartes · المفاهيم والرموز

$?

كود خروج آخر أمر: 0 = نجاح، غير صفر = فشل

Indice : Code retour

$# / $0 / $1

عدد الوسائط / اسم السكربت / الوسيط الأول

Indice : Paramètres

$@ vs $*

"$@" تحافظ على حدود الوسائط، "$*" تدمجها بفاصل IFS

Indice : Quoting

$(cmd) ou `cmd`

استبدال الأمر بناتجه: d=$(date +%d)

Indice : Substitution

${var:-valeur}

قيمة افتراضية مؤقتة إذا كان المتغير غير معرف أو فارغًا

Indice : := يعيّن

(( x = 2 + 3 ))

حساب عددي مباشر ثم echo $((x*2))

Indice : Arithmétique

[ -f f ] / [ -d d ]

اختبار: ملف عادي موجود / مجلد موجود

Indice : test

if …; then …; elif …; else …; fi

بنية شرطية تنتهي بـ fi

Indice : Condition

case … in … esac

اختيار متعدد حسب الأنماط، كل فرع ينتهي بـ ;;

Indice : Choix

for x in liste; do …; done

حلقة على عناصر قائمة أو for ((i=0;i<n;i++))

Indice : Boucle

while / until

while ما دام الشرط صحيحًا؛ until حتى يصبح صحيحًا

Indice : Boucles

function nom { … }

تعريف دالة تُستدعى بدون أقواس؛ return يرجع 0-255

Indice : Fonctions

local x

متغير محلي داخل الدالة فقط

Indice : Portée

source fichier

تحميل ملف داخل الشل الحالي (دوال ومتغيرات)

Indice : vs ./script

tab=(a b c); ${#tab[*]}

مصفوفة وعدد عناصرها (الفهرسة تبدأ من 0)

Indice : Arrays

declare -A tab

جدول ترابطي: tab[cle]=valeur

Indice : Associatif

expr 2 \* 3

حساب بالأمر expr (مسافات وهروب للعمليات)

Indice : Calcul

set -o nounset

خطأ عند استخدام متغير غير معرف

Indice : Options

unset var / declare -r var

حذف متغير / تعريفه كثابت للقراءة فقط

Indice : Variables
